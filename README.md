# ResumeIQ

AI Powered Resume Analyzer built using React, Vite, Tailwind CSS, and Gemini API.

## Features

- Upload Resume PDF
- Extract Resume Text
- ATS Score Analysis
- Strength & Weakness Detection
- Missing Skills Analysis
- AI Suggestions
- Hiring Recommendation

## Tech Stack

- React
- Vite
- Tailwind CSS
- Gemini API
- PDF.js

## Installation

```bash
npm install
npm run dev
```

## Environment Variables

Create a `.env` file:

```env
VITE_GEMINI_API_KEY=YOUR_API_KEY
```
